3. 공통 규칙

  • JSON(UTF-8), 읽기 전용 GET, CORS 허용.
  • 가격 car_price는 만원 정수, 응답마다 price_unit: "만원".
  • 목록·검색 기본 응답에는 긴 텍스트 필드가 없습니다. include=text 또는 상세 API를 쓰세요.
  • per_page 기본 20, 최대 {{ config.API_PER_PAGE_MAX }} (include=text일 때 {{ config.API_PER_PAGE_MAX_WITH_TEXT }}).
  • 렌트 번호(하/허/호), 가격 0 이하 또는 9999 이상 매물은 저장하지 않습니다.

6. 연동 예제

curl -H "X-API-Key: YOUR_KEY" "{{ base_url }}/vehicles?page=1&per_page=20"
import requests
r = requests.get(
    "{{ base_url }}/vehicles",
    headers={"X-API-Key": "YOUR_KEY"},
    params={"page": 1, "per_page": 20},
    timeout=30,
)
r.raise_for_status()
items = r.json()["items"]

7. 증분 동기화

  1. 최초: page를 1부터 늘려 items가 빌 때까지 받습니다.
  2. 이후: 마지막 동기화 날짜를 created_at_from=YYYY-MM-DD로 넘겨 새 매물만 받습니다.
  3. 유일 키는 site_type + site_id, 상세 조회는 db_id.
