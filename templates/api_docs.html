API 명세서

타 프로그램 연동용 조회 API 문서입니다.

API 키로

1. 인증

모든 /api/v1/* 요청에 헤더를 포함합니다.

X-API-Key: <발급받은_API_키>

키가 없거나 비활성이면 401을 반환합니다.

2. Base URL

{{ request.host_url.rstrip('/') }}/api/v1

3. 공통 응답 필드 (차량)

가격 단위는 만원입니다. CSV 업로드 스키마와 동일합니다.

4. 엔드포인트

4.1 목록

GET /api/v1/vehicles
Query: page, per_page(max {{ config.API_PER_PAGE_MAX }}), maker_no, model_no, mdetail_no, grade_no, gdetail_no, maker, model, site_type, year, price_min, price_max, created_at_from, created_at_to
curl -H "X-API-Key: YOUR_KEY" \
  "{{ request.host_url.rstrip('/') }}/api/v1/vehicles?page=1&per_page=20&created_at_from=2026-08-01&created_at_to=2026-08-13"

4.2 검색

GET /api/v1/vehicles/search?q=아반떼

4.3 상세

GET /api/v1/vehicles/{db_id}

경로의 db_id는 응답의 db_id 값입니다.

5. 업로드 CSV 필수 컬럼

아래 컬럼이 반영됩니다. site_type+site_id 기준 upsert, 렌트카(하/허/호)·가격 ≤0 또는 ≥9999는 제외.

id, car_import_yn, site_type, site_id, car_no, car_year, car_km, car_price,
car_maker, car_model, car_submodel, car_grade, car_subgrade, car_fuel,
car_mission, car_color, car_location, detail_info, option_info, diag_info,
