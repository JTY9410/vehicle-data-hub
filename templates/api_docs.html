API 명세서

타 프로그램에서 차량 데이터를 조회할 때 이 문서를 기준으로 호출하면 됩니다.

API 키로

1. 인증

모든 /api/v1/* 요청에 아래 중 하나를 넣습니다. CORS는 허용되어 브라우저·서버 모두에서 호출할 수 있습니다.

X-API-Key: <발급받은_API_키>

# 또는
Authorization: Bearer <발급받은_API_키>

키가 없거나 폐기되면 401과 {"error":"unauthorized"}를 반환합니다.

2. Base URL

{{ request.host_url.rstrip('/') }}/api/v1

운영 예: https://vehicle-data-hub-alpha.vercel.app/api/v1

3. 공통 규칙

  • 응답 JSON, 문자셋 UTF-8.
  • 가격 단위는 항상 만원 (price_unit: "만원").
  • 목록 기본 응답에는 detail_info, option_info, diag_info가 없습니다. 상세 텍스트가 필요하면 include=text 또는 상세 API를 쓰세요 (Vercel 4.5MB 제한).
  • 페이지 기본 per_page=20, 최대 {{ config.API_PER_PAGE_MAX }}. include=text일 때도 동일 상한({{ config.API_PER_PAGE_MAX_WITH_TEXT }})입니다.
  • 없는 상세 id는 404 {"error":"not_found"}.

5. 엔드포인트

5.1 목록

GET /api/v1/vehicles

Query: page, per_page, include=text, maker_no, model_no, mdetail_no, grade_no, gdetail_no, maker, model, site_type, year, price_min, price_max, created_at_from, created_at_to

{
  "price_unit": "만원",
  "page": 1,
  "per_page": 20,
  "total": 204027,
  "fields": ["id", "db_id", "...", "url_link"],
  "items": [ { "db_id": 1, "car_maker": "현대", "url_link": "https://..." } ]
}
curl -H "X-API-Key: YOUR_KEY" \
  "{{ request.host_url.rstrip('/') }}/api/v1/vehicles?page=1&per_page=20"

5.2 검색

GET /api/v1/vehicles/search?q=아반떼

번호·제조사·모델 부분일치, 최대 50건.

5.3 상세

GET /api/v1/vehicles/{db_id}

경로의 db_id는 목록 응답의 db_id입니다. 상세 텍스트 필드를 포함합니다.

6. 연동 예제

import requests
r = requests.get(
    "{{ request.host_url.rstrip('/') }}/api/v1/vehicles",
    headers={"X-API-Key": "YOUR_KEY"},
    params={"page": 1, "per_page": 20},
    timeout=30,
)
r.raise_for_status()
print(r.json()["items"])
const res = await fetch("{{ request.host_url.rstrip('/') }}/api/v1/vehicles?page=1&per_page=20", {
  headers: { "X-API-Key": "YOUR_KEY" },
});
const data = await res.json();
